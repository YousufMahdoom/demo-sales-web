# DEMO SALES WEB — Suzuki Wagon R & Japanese Import Dealer Kurunegala

Welcome to **DEMO SALES WEB**, North Western Province's premier automotive dealership specializing in Suzuki Wagon R mild-hybrids (FX, FZ, Stingray), Honda Fit Crosstar, Toyota Vitz, Nissan Dayz, and premium Japanese vehicle imports in Kurunegala, Sri Lanka.

## Key Features

- **Next.js 16 App Router**: Modern React 19 architecture with static export.
- **UI/UX Pro Max Design System**: Glassmorphism aesthetic, ambient neon mesh gradients, fluid typography.
- **Framer Motion Animations**: Multi-layered background scroll parallax, 3D card tilt, 5-second auto-play slider with linear progress indicator.
- **Interactive Vehicle Modal**: Detailed specs grid, feature tags, photo gallery thumbnails, and direct WhatsApp reservation actions.
- **2-Column Mobile Grid**: Fully responsive mobile layout for seamless browsing.
